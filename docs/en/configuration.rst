Configuration
=============

*Site administration > Plugins > Admin tools > External dependencies*:

* courses and activities included (ended courses, hidden courses and activities, excluded categories and courses);
* time budgets of the tasks and retention of the history;
* statuses that raise alerts.

Each provider has its own page: enabled, requests per minute, timeout, confirmations, recheck intervals and an
optional key (YouTube Data API key, Vimeo token), which makes the checks definitive.

The frequency of the tasks is in *Site administration > Server > Scheduled tasks*.
